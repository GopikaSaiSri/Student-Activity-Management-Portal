# Student Activity Management Portal

## Project Description
This project is a simple Student Activity Management Portal developed as part of Lab Experiment 1.

It allows students to explore university events, view activities and fill out a registration form.

## Technologies Used
- HTML5
- CSS3
- JavaScript
- Git and GitHub

## Features
- Semantic HTML structure
- Navigation bar
- Upcoming events section
- University activities
- Student registration form
- Text fields and dropdowns
- Radio buttons and checkboxes
- Registration success message
- Responsive CSS styling
